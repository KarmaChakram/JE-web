# Electronics Shop Website

A simple, responsive business-front website for an electronics shop. Plain HTML, CSS and JavaScript, with no build step.

## Files

- `index.html`: page content
- `style.css`: styling
- `script.js`: mobile menu and WhatsApp contact form

## Customize

1. Replace **Your Shop Name** in `index.html` (title, logo, footer).
2. Update the address, phone, email and opening hours in the Contact section.
3. Set your WhatsApp number in `script.js` (`WHATSAPP_NUMBER`) and in the WhatsApp link in `index.html`.
4. Edit the product cards and About text to match your shop.

## Publish on GitHub Pages

1. Push these files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/` in a minute or two.
